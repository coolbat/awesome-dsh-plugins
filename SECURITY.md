# Security policy

This repository publishes metadata and review notes. It does not distribute or
execute the listed plugins.

## Reporting a problem

Open a private GitHub security advisory for:

- a secret committed to this repository;
- a malicious link or generated artifact in this repository;
- a validation bypass that could inject unsafe Markdown or URLs.

For a problem in a listed plugin, contact that plugin's maintainer first. You
may also open a correction issue here so the catalog can be held or amended.

## Trust boundary

“Reviewed” means only that native DSH bundle structure was observed at a fixed
commit. It is not a vulnerability scan, malware analysis, sandbox result,
maintainer-identity verification, or runtime compatibility guarantee.
